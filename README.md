# FIRST FALL WORLD DATABASE

2080년대 군사·재난 세계관용 인터랙티브 웹사이트 프로토타입입니다.

## 현재 구현
- 보안 인증 / 부팅 연출
- 인터랙티브 세계지도
- 국가별 현황
- 군사조직 데이터
- 대한민국 중앙사관학교 섹션
- ENEMY 데이터베이스
- 제1강하 연표
- 기밀문서 열람
- 모바일 반응형 UI

현재 국가·연표·에네미 데이터는 프로토타입 임시값입니다.

## GitHub Pages 켜기
1. 저장소에서 **Settings**
2. 왼쪽 메뉴 **Pages**
3. **Build and deployment**
4. Source → **Deploy from a branch**
5. Branch → **main**
6. Folder → **/(root)**
7. **Save**

https://psdt9tn9fy-source.github.io/first-fall-world/
