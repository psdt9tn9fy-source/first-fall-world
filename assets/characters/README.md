# 한서린 이미지

이 폴더에는 사이트 표시용으로 압축한 WebP 이미지만 저장합니다. 원본 JPEG는 저장하지 않습니다.

필요 파일:
- han-seorin-main.webp — 전신 / 전장 배경
- han-seorin-salute.webp — 정복 경례
- han-seorin-casual.webp — 사복
- han-seorin-portrait.webp — 정복 상반신

인물 페이지는 최초 진입 때 첫 이미지 1장만 요청하며 나머지는 선택할 때 읽어옵니다. 파일이 아직 업로드되지 않았다면 기존 이미지 없음 표시가 유지됩니다.
